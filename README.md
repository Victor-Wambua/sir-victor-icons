# Sir Victor icons

Browser icons for Victor Wambua Nthiwa's own web apps, published here only so
they have a public address (some hosts, such as Google Apps Script, can show a
favicon only from a public URL).

| File | Use |
|---|---|
| `favicon.ico` | Browser tab icon (16, 32 and 48 px) |
| `favicon-32.png` | 32 px PNG |
| `favicon.svg` | Scalable icon |
| `apple-touch-icon.png` | Home-screen icon, 180 px |

From the Sir Victor Style Guide: the compact SV monogram on a Midnight Navy tile.
Use the files as supplied; do not re-crop or recolour them.
